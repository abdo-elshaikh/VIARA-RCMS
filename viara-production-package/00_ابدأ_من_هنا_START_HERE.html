إعداد النظام لدى العميل

التثبيت على Linux أو Linux VM داخل Windows Server.

  1. جهّز Docker Engine / Compose وPython 3 وOpenSSL.
  2. استخرج الحزمة وشغّل الأمر التالي من مجلدها:bash setup.sh
  3. أدخل رابطي HTTPS للموظفين والبوابة والترخيص المستلم بشكل منفصل.

الشبكة وشهادات HTTPS والوصول البعيد يجهزها مسؤول الموقع قبل الاستخدام.
