# VIARA Deployment TODO Checklist

- [ ] Confirm release commit or tag.
- [ ] Verify target environment is staging or production.
- [ ] Set production secrets in the secret store.
- [ ] Confirm `NODE_ENV=production`.
- [ ] Confirm `CLIENT_URL`, `PORTAL_CLIENT_URL`, `PORTAL_PUBLIC_URL`, and `ALLOWED_ORIGINS` are correct.
- [ ] Run `docker compose config --quiet`.
- [ ] Install dependencies with `npm ci` in backend, frontend, and portal.
- [ ] Run backend tests.
- [ ] Run frontend lint and tests.
- [ ] Run portal type check and build.
- [ ] Run dependency audit.
- [ ] Deploy database and scanner services first.
- [ ] Run migrations on the target database.
- [ ] Deploy backend.
- [ ] Deploy frontend and portal.
- [ ] Deploy Orthanc and OHIF if included in the release.
- [ ] Run post-deploy smoke tests.
- [ ] Confirm health checks are green.
- [ ] Review logs for errors or leaked secrets.
- [ ] Keep rollback plan ready and validated.
