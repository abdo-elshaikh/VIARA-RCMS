# أدلة مراجعة تعدد الفروع — 2026-10-14

البيانات في هذه الملفات ناتجة عن اختبارات اصطناعية. لا تحتوي كلمات مرور أو مفاتيح أو بيانات مرضى حقيقيين.

| الملف | المحتوى |
|---|---|
| database.json | اختبارات المخطط الحقيقي، التفويض، الإسناد، الحصص، الأداء، والاستعادة وتزوير السياق بعدها |
| frontend.json | اختلاف فرع التبويبات والفرع غير المصرح بعد إعادة الجلسة |
| realtime.json | نطاق بيانات اتصال SSE والتوزيع بين الفروع |
| runtime.json | لقطة قراءة فقط لحاويات Docker وأعلام صلاحية الإعداد دون قيم أسرار |
| baseline.json | نتائج إعادة الاختبارات القائمة؛ لا تغطي وحدها النتائج الجديدة |
| source-manifest.json | بصمات SHA-256 لملفات المصدر وقت إعداد التقرير |

اختبارات إعادة الإنتاج موجودة في `scripts/fixtures/audit-multibranch-*-postfix.*`. تُشغَّل من جذر المستودع كما هو موضح في التقرير. الاختبار الأول ينشئ قاعدة منفصلة مؤقتة؛ لا يجوز تحويله لاستعمال قاعدة العميل بدلاً منها.

`completed=true` يعني اكتمال تنفيذ probe، وليس اجتياز بوابات الأمان. المرجع لتفسير كل حقل هو التقرير وقائمة النتائج؛ جميع النتائج الـ13 مفتوحة وقت إعداد هذه الأدلة.
