# تطوير «ابدأ من هنا» — VIARA

أعيد تصميم دليل الإعداد المحلي باللغة العربية واتجاه RTL وبهوية VIARA: شعار أصلي، ألوان خضراء، أربع خطوات، تنقل واضح، اختيار Linux أو Windows Server مع توضيح Linux VM، خمسة أوامر قابلة للنسخ، قائمة تحقق يدوية، مساعدة وتشخيص وطباعة. يعمل الدليل دون إنترنت أو تخزين أسرار أو جمع بيانات.

## التحقق المنفذ

- فحص Chromium بفتح الملف محلياً على عروض 320 و390 و768 و1440 بكسل: الشعار والاتجاه صحيحان، لا تمرير أفقي ولا أخطاء JavaScript أو طلبات خارجية.
- فحص axe الآلي لمعايير WCAG A/AA دون مخالفات مسجلة على الأحجام الأربعة. هذا فحص آلي وليس شهادة توافق شاملة.
- اختبار تغيير بيئة الخادم، الروابط، فتح وإغلاق الأسئلة، تقدم القائمة وإعادتها للصفر بعد التحميل، والطباعة وإنتاج PDF.
- اختبار كتابة وقراءة الحافظة الفعلية في Chromium، والتنقل بلوحة المفاتيح ورابط التخطي وEnter، وأزرار النسخ الخمسة عبر محاكاة نجاح Clipboard API ورفضه والنسخ القديم ثم النسخ اليدوي؛ لا يضمن ذلك صلاحية الحافظة في كل متصفح.
- تشغيل الأوامر الخمسة المستخرجة من HTML على Docker Linux فعلي ضمن مشروع اصطناعي مستقل: فحص الأدوات، الإعداد، حالة الخدمات، config --quiet، وآخر 80 رسالة للخادم. اختُبر الإعداد الأول باستخدام خيار settings-file الموثق ببيانات مصطنعة؛ ثم شُغّل أمر bash setup.sh نفسه دون خيارات على الموقع المعد مسبقاً.
- التحقق من تحميل أرشيفات الصور وبصماتها، إنشاء قاعدة وترحيلها، جاهزية الخدمات الثماني، إنشاء المدير وتسجيل دخوله، حفظ الحسابات والمفاتيح عند إعادة التشغيل، رابط البوابة وقت التشغيل ورفض مسارات الموظفين من البوابة.

بيئة اختبار الأوامر: Windows Git Bash متصل بمحرك Docker Linux، مع موائم Python 3. لم تُستخدم بيانات عميل أو ترخيص عميل؛ مفتاح التحقق البديل خاص بالاختبار. حُذفت حاويات ووحدات بيانات المشروع الاصطناعي وحده بعد الاختبار. الاختبار لا يعادل قبول خادم Linux إنتاجي لدى العميل.

الأدلة: [نتائج المتصفح](reviews/start-here-2026-10-09/browser-results.json)، [نتائج الأوامر](reviews/start-here-2026-10-09/command-results.json)، [نتائج الخدمات](reviews/start-here-2026-10-09/container-results.json)، [الدليل المطبوع](reviews/start-here-2026-10-09/guide.pdf). اجتازت اختبارات معالج الإعداد الخمسة واختبارات التغليف والسلامة الستة عشر أيضاً.
